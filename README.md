# YouTube Video Downloader

Este es un sencillo script de Python que permite descargar videos de YouTube utilizando la biblioteca `yt-dlp`. La interfaz gráfica está creada con Tkinter, lo que facilita el proceso de descarga.

## Descripción

El script `youtube.py` proporciona una interfaz gráfica simple para descargar videos de YouTube. Solo necesitas pegar la URL del video en el campo de entrada y hacer clic en el botón "Download". El video se descargará automáticamente en la carpeta especificada.

## Requisitos

Para ejecutar este script, necesitarás tener instalados los siguientes paquetes:

- Python 3.x
- `yt-dlp`
- `tkinter`

Además, necesitarás tener `ffmpeg` instalado en tu sistema para combinar los formatos de video y audio.
